# Contributing Guidelines

Thank you for contributing! Contributions, issues and feature requests are welcome.

## Pull Requests
1. Fork the repo and create your branch from `main`
2. Commit with clear messages using [Conventional Commits](https://www.conventionalcommits.org/)
3. Open a Pull Request describing your changes

## Commit Convention
- `feat:` new feature | `fix:` bug fix | `docs:` docs | `chore:` maintenance

## Code of Conduct
Follow the [Contributor Covenant](https://www.contributor-covenant.org/).
